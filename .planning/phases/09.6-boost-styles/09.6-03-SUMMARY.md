# Phase 09.6 Plan 03: Ring + tier-badges boost detail body Summary

**Added `RingBadgesBody` — a 160px conic-gradient ring bound to the same week.total/week.max fraction as the inline BoostMeter, 3 tappable grade-tier badges with a single-open-at-a-time behavior-first popover, and a 7-dot week strip + reused streak chip — completing `BoostDetailSheet`'s style router as a full 3-way branch.**

## Performance

- **Duration:** ~20 min
- **Completed:** 2026-09-20
- **Tasks:** 2/2 completed (as 2 separate commits, each independently type-checked and build-verified)
- **Files modified:** 1

## Accomplishments

- `RingBadgesBody({ v, t, boost, reduced })` renders, top to bottom: a 160×160 conic-gradient ring (`conic-gradient(K.mango {pct}deg, K.line 0deg)`, guarded against `week.max === 0` via a ternary that renders `0deg` instead of `NaN`/`Infinity`) with a 14px inset "hole" showing `+{total}` and a "сейчас" label; a 3-badge row (🥉🥈🥇, 46px circles) with 4 mutually exclusive visual states — reached (`K.mango`/`K.mangoSoft`), next-unreached (`K.sky` outline + static glow, D-09), not-reached (`K.line`/`K.lineSoft`), penalized (`K.danger`/`⚠`, all 3 badges simultaneously); a `penaltyHint` line once beneath the badge row when penalized; a `K.card` consistency block with a 7-dot week strip (`v.consistency.filledDayFlags`, Monday first) and the segmented-bar's exact streak chip JSX copy-pasted verbatim (D-07)
- Tapping a badge opens a single popover (`openTierId: 1|2|3|null` state) positioned above the badge (`bottom: calc(100% + 8px)`, centered) with `K.ink` background/white text; tapping a different badge closes the first before opening the second (D-10, for free from the single-value state); a transparent full-body backdrop (`zIndex: 1`, beneath the badge row's `zIndex: 2`) closes an open popover on any other tap in the sheet body without calling `onClose` (D-11, independent of the `BottomSheet`'s own explicit-close rule)
- Popover copy leads with the achievement/condition and shows the coin amount as a visually secondary line (D-12): `ringPopReachedTitle`/`ringPopPerfectReachedTitle` + `ringPopCoinsEarned` when reached, `ringPopNextTitle`/`ringPopPerfectNextTitle` + `ringPopCoinsPending` when not — a penalized badge's popover falls back to the not-yet-reached template automatically (D-15), since `showReached` is forced `false` whenever `v.grades.penalized` is true
- `BoostDetailSheet`'s render branch is now a complete 3-way ternary: `'quest-checklist' → QuestChecklistBody`, `'ring-badges' → RingBadgesBody`, else `SegmentedBarBody` — the two prior bodies are untouched (confirmed via diff review, only additive lines)
- Reduced-motion double-guard: the popover's `transition: 'opacity .15s, transform .15s'` is applied only when `!reduced` (threaded in from the main component's existing `reduced` state, same pattern as `SegmentedBarBody`)
