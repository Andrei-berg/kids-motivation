# Phase 09.6 Plan 02: Quest-checklist boost detail body Summary

**Extracted the segmented-bar hero card into its own `SegmentedBarBody` function and added `QuestChecklistBody` — 6 independent boost-condition rows (3 grade tiers + full-week + streak×2 + streak×3) with a real combined total, all data-bound to the settings-derived view model from Phase 9.6 Plan 01.**

## Performance

- **Duration:** ~15 min
- **Completed:** 2026-09-20
- **Tasks:** 2/2 completed (executed as one combined diff/commit per the plan's own instruction — task 1 alone leaves a dangling `QuestChecklistBody` reference)
- **Files modified:** 1

## Accomplishments

- `BoostDetailSheetProps` gained an optional `boostStyle?: Child['boost_style']` prop (safe-defaults to `'segmented-bar'`)
- The pre-existing 150-line hero card (gradient card, grades sub-bar, consistency sub-bar, total row, explainer note) moved verbatim into a new `SegmentedBarBody({ v, reduced, t, boost })` function — zero style/class/copy-key/attribute changes, confirmed via `git diff` review
- New `QuestChecklistBody({ v, t, boost })` renders, top to bottom: a 3-row grade-tier card (each row independently reached via `v.grades.tiers[i].reached`, D-03's "higher tier reached ⇒ lower tier still shows checked" satisfied because each tier's own `reached` boolean already accounts for `current >= threshold` independently), a `questNote` explainer beneath the group (D-04), a 3-row consistency card (full-week / streak×2 / streak×3, never penalty-tinted), a combined total row reusing `v.total.toLocaleString('ru-RU')` verbatim (not a sum of the 6 rows), and a total progress bar reusing `boost.week.nextLabel` verbatim
- D-15 penalty override: when `v.grades.penalized` is true, all 3 grade rows switch to the shared muted-danger treatment (`${K.danger}1F` background, `${K.danger}55` border, `⚠` glyph replacing the check-circle content, `K.danger` reward color) with `penaltyHint` rendered exactly once beneath the group, never per-row
- Top-level `BoostDetailSheet` render is now a 2-way branch: `boostStyle === 'quest-checklist' ? <QuestChecklistBody/> : <SegmentedBarBody/>` — any value other than `'quest-checklist'` (including the current `undefined` at both real call sites) renders the unchanged segmented-bar body
