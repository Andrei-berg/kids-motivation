## Decisions Made
- `isOwnCard` covers both a parent's own note (`actor_member_id === me.id`) and a child's own system-authored card (`child_id === me.childId`) — matches D-05's intent that a card of any kind can be teased except your own
- No optimistic tease insert — unlike reactions, a tease is a one-shot permanent action; the bubble appearing on server round-trip is the honest signal (a rolled-back optimistic bubble would look like a delivered tease)
- Tray/bubble use the locked `6px 12px` / `6px 11px` / `1px dashed` sketch values verbatim (UI-SPEC exception list), not rounded to the 8pt spacing scale
