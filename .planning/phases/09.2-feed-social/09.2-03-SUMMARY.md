## Accomplishments
- Reaction chips on every feed card (kid, parent, family variants) now offer all 6 allowed emoji, driven by the shared `FEED_REACTION_EMOJI` constant instead of a local hardcoded 4-emoji list
- Tapping a chip pops it (scale 1.28 at 40%, 0.35s ease) every time, only the tapped chip, never on initial render — implemented via a per-chip `popKey` counter that changes both the chip's `key` (forcing remount so the CSS animation replays) and its `className`
- Landed `feed-tease-slide-in` / `.feed-tease-reply` keyframes in `globals.css` now, so plan 09.2-05 (tease reply bubble) never needs to touch this shared file
- Both new animations are disabled under `prefers-reduced-motion: reduce`
