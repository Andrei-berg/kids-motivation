**New `MedalComposer.tsx` bottom sheet (sibling picker + 8 berry-styled D-11 phrase buttons calling `sendKidMedal`) plus a kid-only "🏅 Отправить медаль" launcher wired into `FamilyFeed.tsx`, closing out FEED-07's client-side gap.**

## Accomplishments
- `components/feed/MedalComposer.tsx`: kid-only surface (sources `K` tokens directly, no daylight palette) rendering a two-step flow — sibling picker when there's a choice, then the 8 locked phrases as full-width berry pill buttons. Tapping a phrase sends immediately via `sendKidMedal`; a hit on the sender-side daily cap replaces the list with the locked cap copy and a Закрыть button; any other server error renders inline as small red text below the list.
- `FamilyFeed.tsx`: added `canSendMedal` (kid variant + child role + at least one sibling) and a `siblings` `useMemo` derived from the already-loaded `children` state (no new query). The launcher pill occupies the same vertical slot the note composer leaves empty for kids (`canPost` requires `variant !== 'kid'`, so the two never render together). The sheet mounts beside the existing `StoryMomentModal`.
- End-to-end FEED-07 flow now closed: feed launcher → composer → `sendKidMedal` (09.2-02) → `medals` insert + `family_events` emit → card renders via the existing `EventRow` (zero card-render changes needed, per D-12 — the title is composed server-side at emit time).
