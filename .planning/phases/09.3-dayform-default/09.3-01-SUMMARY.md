## Decisions Made
- All three style literals included in the CHECK constraint now (not just `sticky-summary`) so Phase 9.4 needs no second migration — matches plan/CONTEXT.md D-02 guidance.
- The D-01 "not available yet" reject is enforced in the server action itself (not only omitted from the UI), so no stray client code can force an unbuilt style even by calling the action directly.
- Control kept to a single confirmation pill (Claude's Discretion per D-01/CONTEXT.md) rather than building a `FillStylePicker.tsx` sheet component — there's only one real choice this phase, so a full picker component would be premature.
