  <action>
    Create `lib/kid/day-fill-progress.ts` (pure, no React, no imports from `components/`) exporting:

    `export interface FillProgress { doneCount: number; total: number; pct: number }`
    `export function computeFillProgress(applicable: Record<string, boolean>, done: Record<string, boolean>): FillProgress`
    — `total` = number of keys in `applicable` whose value is `true`; `doneCount` = number of those
    same keys for which `done[key] === true`; `pct` = `total === 0 ? 0 : Math.round(doneCount / total * 100)`.
    Keys present in `done` but not `true` in `applicable` are ignored entirely. Document in a comment
    that this encodes D-09: a category with nothing configured for this child is excluded from both
    numerator and denominator (never a stuck 0/1 slice), and that a multi-sub-item category
    (e.g. several grade subjects) is ONE slot because the caller passes one boolean per category.

    `export interface CoinDelta { key: string; delta: number }`
    `export function diffSectionCoins(prev: Record<string, number>, next: Record<string, number>): CoinDelta[]`
    — iterate `Object.keys(next)` then `Object.keys(prev).filter(k => !(k in next))`; delta =
    `(next[k] ?? 0) - (prev[k] ?? 0)`; drop zero deltas. Document that this is the D-12 delta source:
    it derives every per-row coin flyup from the already-computed `sectionCoins` map, so no coin
    amount is ever recalculated or invented client-side, and that a removed key yields the exact
    negative inverse (D-10 untoggle, D-11 loss).
