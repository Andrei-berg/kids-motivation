# Phase 09.3 Plan 03: Sticky-Summary Building Blocks Summary

One-liner: Pure D-09/D-12 completion-ring and coin-delta maths (12 unit tests) plus three
presentational sticky-summary components (ring header, one-tap row, in-place panel row) built
with zero coupling to `KidDayFillForm`, ready for Phase 9.4 reuse.

## What Was Built

**Task 1 — `lib/kid/day-fill-progress.ts` + `tests/day-fill-progress.test.ts`**
Two pure functions, no React/component imports:
- `computeFillProgress(applicable, done)` — the D-09 completion-ring rule: only categories with
  `applicable[key] === true` count toward the denominator; a category with nothing configured
  for this child is excluded entirely (never a stuck incomplete slice). `pct` rounds via
  `Math.round`.
- `diffSectionCoins(prev, next)` — the D-12 per-row coin-delta source: diffs two `sectionCoins`
  snapshots, iterating `next` keys first then `prev`-only keys (D-10 untoggle → negative
  inverse), dropping zero deltas. No coin amount is recalculated — only subtracted from the
  existing preview map.
- 12 unit tests, all passing, covering every case enumerated in the plan's `<behavior>` block
  (empty-map no-divide-by-zero, D-09 exclusion, D-10 untoggle, D-11 negative-value passthrough,
  no-op re-render, simultaneous multi-key diff with ordering).

**Task 2 — `components/kid/day-fill/StickySummaryBar.tsx`**
A ≤70px `'use client'` presentational sticky header: `ProgressRing` (56px, `K.mint` fill) wrapped
in `<span role="img" aria-label={ringLabel}>` for accessibility, `AnimatedNum`-driven live coin
total (`K.mangoDeep`, 20px/900) + `Coin`, a caption, and an optional locked-state pill. All copy
arrives via props (`pct`, `coins`, `caption`, `ringLabel`, `lockedLabel`) — no `useT()` call
inside, so Phase 9.4's other fill styles can reuse it unchanged.

**Task 3 — `components/kid/day-fill/QuickRow.tsx` + `components/kid/day-fill/InlinePanelRow.tsx`**
- `QuickRow`: the entire row is a `<button role="switch" aria-checked={done}>` — D-05's one-tap
  binary interaction. Forwards the click event unchanged to `onToggle` so the consumer can anchor
  a coin-flyup at `e.currentTarget.getBoundingClientRect()`. A 44×26px track + 20×20px thumb
  switch slides via `translateX(18px)`. Re-tapping a done row is a free toggle-back (D-10) — no
  confirm step, `disabled` prop sets the native attribute for locked-day/parent-fill gating.
- `InlinePanelRow`: same row anatomy as `QuickRow` but the header ends in a rotating chevron
  (`aria-expanded={open}`) instead of a switch; the panel (`children`) renders directly below the
  header inside the same card via `open &&` — no portal, no `position: fixed`, no
  `translateY(100%)` sheet, satisfying D-06/D-07's "in place" requirement. Comment warns
  consumers to render at a stable position/key so controlled panel inputs are never remounted.
