# Phase 09.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| `window.localStorage` (same-origin, per-device) | Story-seen booleans, written/read only through `feed.repo.ts` helpers | Cosmetic UI state only (ring flat vs gradient) — no data access, no authorization role |
| Postgres `family_events` (RLS SELECT-only for clients) → browser render | Already-authorized, family-scoped rows already present in component state are rendered in the restyled cards, story reel, and modal | Existing feed event content (title/body/icon/kind); no new query, no new write, no new server call added by this phase |
